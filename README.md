# WealthPath Finance Blog

A clean, professional personal finance blog targeting the US/European market. Built for Google AdSense monetization with placeholder ad slots ready to be configured.

## Features

- 📱 Fully responsive design (mobile-first)
- 💰 Ad slots pre-placed (leaderboard + rectangle) for Google AdSense
- 🔍 SEO-optimized meta tags
- 📰 Article grid with categories
- 💌 Newsletter signup form
- 🎨 Modern, professional finance branding

## Monetization Setup

1. Apply for [Google AdSense](https://adsense.google.com)
2. Once approved, replace the `ad-placeholder` divs in `index.html` with your AdSense ad unit code.
3. Add affiliate links to articles for extra revenue.

## Customization

- Edit `index.html` to change articles, text, and structure.
- Edit `css/style.css` to change colors and styling (CSS variables at top).
- Edit `js/main.js` for interactivity.

## Deployment

Deployed via GitHub Pages.
